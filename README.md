# Sahil's Portfolio Website

A modern personal portfolio website built to showcase skills, projects, and professional experience.

## Overview

This project is a responsive portfolio website developed with:

- HTML5
- CSS3
- JavaScript

It includes sections for home, about, skills, projects, GitHub integration, and contact information.

## Features

- Responsive navigation with mobile menu support
- Animated hero section with typing effect
- Skills section with animated progress bars
- Projects section with GitHub repository links
- Dynamic GitHub repository fetching using the GitHub API
- Contact form with validation and notifications

## Project Structure

- `index (3).html` - Main HTML page
- `styles.css` - Styling and layout
- `script.js` - Interactivity and GitHub API integration
- `profile.jpg` - Profile image used in the hero section
- `README.md` - Project documentation

## Usage

1. Open `index (3).html` in a web browser.
2. Ensure an internet connection is available for the GitHub repository section to load.

## Notes

- The GitHub section currently fetches repositories from the GitHub user `Sahil9817`.
- Update the username or repository links in `script.js` and `index (3).html` if needed.
